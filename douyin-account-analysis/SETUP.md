# 配置指南（给用户看）

这个技能要在你电脑的 Chrome 里打开抖音，读你的创作者中心数据，搜同题材作品。
支持 **Mac 和 Windows**，每个系统都有两种模式，选一种配置即可。

**你不需要输入任何命令。** 下面每一步都是点菜单或者双击文件。需要运行命令的地方，由你使用的 AI 助手（Claude Code、Codex、Cursor、Gemini CLI 等能在你电脑上执行命令的工具）自己执行。

## 先选模式

| | 调试模式（推荐） | 截图模式 |
|---|---|---|
| 原理 | AI 直接读网页里的数据 | AI 截屏看页面，模拟鼠标去点 |
| 运行时能不能用电脑 | **能**，在后台标签页里跑 | **不能**，Chrome 要一直在最前面，鼠标会自己动 |
| 准确度 | 高，读的是原始数字（包括图表里的数） | 靠看图读数字，偶尔看错 |
| 速度 | 快 | 慢 |
| 代价 | Mac 要打开 Chrome 的一个开关；Windows 要用一个单独的 Chrome 窗口，并在里面登录一次抖音 | 要给运行 AI 的程序授予屏幕录制等权限；AI 要能看图 |

两种模式都只读数据，不会帮你点赞、评论、删除或修改作品。

---

## Mac · 调试模式

1. 打开 Chrome，点屏幕最上方菜单栏的 **「查看」→「开发者」→「允许 Apple 事件中的 JavaScript」**，让它前面出现 ✓。
   如果菜单是英文的，就是 View → Developer → Allow JavaScript from Apple Events。
2. 在 Chrome 里登录 **creator.douyin.com**（抖音创作者中心）。
3. 第一次运行时，macOS 会弹窗问「终端（或你用的 AI 应用，例如 Claude、Codex、Cursor）想要控制 Google Chrome」，点 **「允许」**。
   如果之前点过「不允许」：打开「系统设置 → 隐私与安全性 → 自动化」，找到终端或那个 AI 应用，勾选它下面的 Google Chrome。

**安全提醒**：这个开关打开后，你电脑上所有获得「自动化」权限的程序，都能在你已登录的网页里执行代码。不分析的时候，建议回到同一个菜单把 ✓ 去掉。

## Mac · 截图模式

1. 打开「系统设置 → 隐私与安全性」，给运行 AI 的程序（终端，或者 AI 桌面应用、编辑器）开两项权限：
   - **屏幕与系统录音**（旧版系统叫「屏幕录制」）：打开它的开关；
   - **辅助功能**：同样打开它的开关。
   第一次截图时，系统也会自动弹窗问你，点「允许」就行。改完权限后，可能要把终端退出再重新打开一次。
2. 在 Chrome 里登录 **creator.douyin.com**。
3. 运行期间不要碰鼠标和键盘，也不要让别的 AI 工具同时控制 Chrome。

## Windows · 调试模式

1. 在技能文件夹 `scripts\windows\` 里，**双击「启动抖音分析Chrome.bat」**。
   - 它会打开一个**单独的 Chrome 窗口**，和你平时用的 Chrome 互不影响，书签和登录状态都是分开的；
   - 第一次运行时，还会在桌面建一个快捷方式「抖音分析专用Chrome」，以后双击那个快捷方式就行；
   - 如果 Windows 提示「已保护你的电脑」，点「更多信息 → 仍要运行」。
2. 在这个新窗口里，**扫码登录抖音创作者中心**。只要登录一次，以后会一直保持。
3. 回到 AI 助手，告诉它「好了」。

**安全提醒**：这个专用窗口开着的时候，本机上的程序可以控制它，但它只监听本机，外网连不进来。分析完就把这个窗口关掉。

## Windows · 截图模式

1. 在你平时用的 Chrome 里登录 **creator.douyin.com**，把窗口**最大化**。
2. 运行期间不要碰鼠标和键盘，也不要让 Chrome 最小化。
3. 不需要额外授权。如果公司电脑禁止运行 PowerShell 脚本，就改用调试模式，或者找 IT 放行。

## 常见问题

- **两个 AI 能同时操作 Chrome 吗？** 不行。比如 ChatGPT / Codex 也在控制 Chrome 时，两边会互相切换标签页、抢焦点。请一次只运行一个。
- **会不会被抖音风控？** 这个技能只读数据，频率和人工浏览差不多，风险较低。但不要让它连续几个小时不停地刷。
- **数据显示「计算中」**：发布不到 48 小时的作品，很多数据还没有算完，这是正常的。
